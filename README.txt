CyberGenics booth experiences
=============================

How to open
1. Unzip this folder anywhere (keep all files together, including the "lib" folder).
2. Double-click index.html. It opens in your browser.
3. Choose an experience. Press F11 for full screen.

Pages
- index.html     Menu of all experiences
- universe.html  Particle universe (DNA, domains, managed services)
- planets.html   Planet view, one planet per domain
- solar.html     Solar system map with Protect / Defense / Risk orbits
- managed.html   Managed Security Services showcase (Protect, Defense, Risk)
- tour.html      Story tour: Why CyberGenics, then Protect, Defense, Risk

Works offline: the 3D library is inside the "lib" folder.
Without internet the Sora font falls back to a system font; everything else works the same.

Best in Google Chrome or Microsoft Edge with hardware acceleration turned on.
Each page starts an automatic tour after 30-35 seconds with no touch.
